Productivity Dashboard

A clean and responsive task management dashboard built with HTML, CSS, and JavaScript. Designed to help users organize daily tasks with priority levels, due dates, progress tracking, and a distraction-free interface.

## Live Demo

🔗 https://to-do-dashboard-nine.vercel.app

## Features

* Create and manage tasks
* Set task priorities
* Add due dates
* Filter tasks (All, Active, Done, Today)
* Progress tracking dashboard
* Task statistics overview
* Light/Dark mode toggle
* Local Storage persistence
* Responsive modern UI

## Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Git & GitHub
* VercelInstallation

Clone the repository:

```bash
git clone https://github.com/selrio-spec/to-do-dashboard.git
```

Open the project folder:

```bash
cd to-do-dashboard
```

Run locally by opening `index.html` in your browser or using a local development server.
